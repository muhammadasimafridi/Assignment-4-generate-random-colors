# 🎨 Random Color Changer App

A simple and interactive **Random Color Generator Web App** built using HTML, CSS, and JavaScript. This app generates a random RGB color and applies it to the background with a single button click.

---

## 🚀 Features

* 🎲 **Random Color Generation** – Generates random RGB values on each click
* 🎨 **Dynamic Background Change** – Instantly updates the page background color
* 🧾 **Color Code Display** – Shows the current RGB value on screen
* 🖱️ **User Interaction** – Trigger color change with a button

---

## 🧠 Concepts Used

* DOM Manipulation
* Event Handling (Click Events)
* Random Number Generation
* Dynamic Styling (CSS via JavaScript)

---

## 📂 Project Structure

* `HTML` → Page structure and elements
* `CSS` → Basic styling and layout
* `JavaScript` → Logic for generating and applying colors

---

## 🎯 How It Works

1. User clicks the **Generate Random Color** button
2. Three random values (Red, Green, Blue) are generated (0–255)
3. These values form an RGB color
4. The background color updates instantly
5. The RGB code is displayed on the screen
